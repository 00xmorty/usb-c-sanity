# Responsible Use

Use this tool to collect clues, not verdicts.

Good uses:

- compare the same device and port across two cables;
- capture macOS-exposed negotiated speed/current hints before troubleshooting;
- produce a redacted report for a support request;
- identify when a hub/dock/device path is involved.

Bad uses:

- declaring a cable fake from one run;
- publishing unredacted serial numbers or location IDs;
- treating missing fields as negative proof;
- using the report as a safety, charging, or compliance certification.

Recommended wording:

> In this setup, macOS observed this device path negotiating at [speed/current fields]. This does not guarantee the cable’s rated capacity.
